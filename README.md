# JuteOrb Website

Static website prototype for JuteOrb. Open `index.html` to preview the storefront.

## Pages

- `index.html` — home page and featured collections
- `pages/collections.html` — product categories
- `pages/about.html` — brand and founder story
- `pages/contact.html` — customer, artisan and bulk enquiries
- `account/` and `admin/` — browser-only account and administrator prototypes

## Assets

Website images, video, styles and scripts are organized under `assets/`.
Product and founder images are in `assets/images/`.

## Prototype limitations

The account, checkout and administrator experiences are front-end prototypes. They do not use a secure server, payment processor, live order service or shared database. Demo account checks and browser-stored data are not suitable for protecting real accounts or customer information. Add secure server-side authentication and services before using this site for real transactions or private data.

This project is a static site and has no build step. The root `index.html` is the entry page for static hosting.
